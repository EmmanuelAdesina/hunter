Why this isn't a generic CLI skin

Generic CLIs print tables. Reliastra renders verdicts — a gold banner answers "is there anything worth my evening?" in under a second, then evidence unfolds below. Coverage is always on screen, so trust is continuously earned, never assumed.

⬢

Enterprise constraints, honored

No new dependencies — the theme engine is internal/tui/theme.go in stdlib ANSI. NO_COLOR + dumb-terminal fallback. --json output is byte-identical. Styling lives only in render code, never in policy.

◎

What happens next

Approve this direction and we implement it command by command behind a --theme obsidian|plain flag, starting with scan. Plain stays default in CI; Obsidian activates on TTY. Screenshots in this demo become golden tests.
